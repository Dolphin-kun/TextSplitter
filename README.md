# 「テキスト分割」プラグイン

### [最新バージョンをダウンロード](https://github.com/Dolphin-kun/TextSplitte/releases/latest)

## 概要
テキストを文字ごとに別のアイテムとして分割することができるツールプラグインです。  
__バージョンチェッカー入れてません。__

## 使い方
1. 画面右上のメニューバーから、`ツール`内にある「テキスト分割」を選択してください。
2. テキストアイテムを選択している状態でボタンを押すと分割されます。
